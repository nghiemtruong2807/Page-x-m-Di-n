WEBSITE XÓM DIỄN - GIAO DIỆN TĨNH

1. Cấu trúc:
   index.html
   tong-quan.html
   ve-xom-dien.html
   hoi-trai-trung-thu.html
   hanh-trinh-khoanh-khac.html
   css/style.css
   js/main.js
   images/

2. URL khi chạy Live Server (mặc định):
   http://127.0.0.1:5500/index.html
   http://127.0.0.1:5500/tong-quan.html
   http://127.0.0.1:5500/ve-xom-dien.html
   http://127.0.0.1:5500/hoi-trai-trung-thu.html
   http://127.0.0.1:5500/hanh-trinh-khoanh-khac.html

3. Cách chạy:
   - Giải nén ZIP.
   - Mở thư mục bằng VS Code.
   - Mở index.html.
   - Chọn Open with Live Server hoặc Go Live.
   - Nếu cổng khác 5500, URL sẽ có cổng khác; dùng URL mà Live Server hiển thị.

4. Lưu ý:
   - Không có database/backend.
   - Các menu đã có URL nội bộ.
   - Ảnh SVG trong images chỉ là ảnh mẫu để project chạy ngay; thay bằng ảnh thật của Xóm Diễn.
   - Tìm kiếm hiện là giao diện mẫu, chưa có backend.
